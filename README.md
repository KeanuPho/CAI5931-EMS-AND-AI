# AI-Driven EMS Call Volume Prediction
CAI 4930/5931 | Group Project | University of West Florida

## Project Overview
This project investigates the effectiveness of AI-driven predictive analytics 
systems in improving ambulance deployment efficiency and EMS response times 
compared to traditional deployment methods.

## Research Question
How effective are AI-driven predictive analytics systems in improving ambulance 
deployment efficiency and EMS response times compared to traditional deployment 
methods?
